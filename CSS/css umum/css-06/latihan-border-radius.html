latihan Border Radius

Border Radius akan membuat pojok di bagian elemen jadi tumpul tidak berbentuk siku, tapu berbentu lingkaran. Biasanya nilai Radius ditentukan dengan satuan pixel, persen, em, dll. Kalau nilai 100% berarti sudut lingkaran penuh, yakni 260 derajat. Silakan coba - coba eksperimen sendiri dengan mengganti nilai pada properti border-radius
